# 教学日历桌面挂件 — 最终版规划文档

> 参考样式：小智桌面日历组件（悬浮月历 + 待办）
> 创建于 2026-06-25 | 状态：已确认

---

## 一、需求（已确认）

桌面悬浮小窗口，参考"小智桌面"日历风格：

1. **月历视图** — 6×7 网格，周一到周日，公历日期
2. **教学周标记** — 在教学周的日期前方标注周次（W1、W2…）
3. **今日高亮** — 当天日期突出显示
4. **待办管理** — 双击日期创建待办事项
5. **文件上传** — 支持 XLS/XLSX / PDF / Word / 图片
6. **月份导航** — 左右箭头切换月份
7. **无边框置顶** — 可拖动、记住位置

## 三、系统架构

```
文件上传 → 解析引擎 → 提取教学周日期范围
                                    ↓
月历组件 ←────────────────────────────┘
   ├── 日期网格（公历 + 教学周标记 W1-W25）
   ├── 今日高亮
   ├── 待办列表
   └── 月份导航
                                    ↓
                            Electron 桌面窗口
                            （置顶、半透明、可拖动）
```

## 四、数据结构

```typescript
interface TeachingCalendar {
  id: string
  fileName: string
  fileFormat: string
  semester: string
  teachingWeeks: TeachingWeekRange[]  // 解析出的教学周
  createdAt: string
}

interface TeachingWeekRange {
  weekNumber: number
  startDate: string   // ISO
  endDate: string
  content: string[]   // 本周教学内容
}

interface TodoItem {
  id: string
  date: string
  content: string
  completed: boolean
  createdAt: string
}

interface CalendarDay {
  date: string
  isCurrentMonth: boolean
  isToday: boolean
  teachingWeek?: number   // 在教学周内则标注周次
  todos: TodoItem[]
}
```

## 五、技术栈

| 组件 | 技术 |
|------|------|
| 桌面框架 | Electron |

## 六、开发路线（Phase 1）

1. 项目骨架 + Electron 窗口（置顶、拖动、托盘）
2. 月历基础组件（6×7 网格 + 月份切换 + 今日高亮）

5. 数据持久化（electron-store）
